# AutoCare — Car Detailing & Service Booking

A marketplace connecting car owners with garages and automobile workshops.

## Project Structure
- `data`: Contains data models and repositories for Firestore integration.
- `navigation`: Contains Jetpack Compose navigation graph.
- `ui`: Contains Jetpack Compose UI screens, themes, and reusable components.
